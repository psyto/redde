# Generated-data status

`swarm.json` and `swarm-partial.json` were generated before the route-verification
and sampling-boundary rules in `SPEC.md`. They are retained as reproducibility
artifacts only. Do not use their owners, classes, shares, or `decisiveT` values as
participant attribution or population statistics; regenerate them with the current
`swarm.mjs` before any use beyond an explicitly labelled exploratory sample view.

`curve-usdc.json` similarly predates the current `sampledPeak` /
`sampledPostPeakTrough` output schema. Its points remain source observations, but
the producer should be rerun before publication.
